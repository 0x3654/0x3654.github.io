чистую лампу — ставит плагины и применяет настройки.

```
https://0x3654.github.io/t.js
```

Исходники и серверная часть — [transmission-send](https://github.com/0x3654/transmission-send)
(длинная копия того же файла — `t.js` там; при правке CONFIG синхронизировать).
